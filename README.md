# 📝 Notes App

A simple and responsive **Notes App** built using **HTML, CSS, and JavaScript**. This application allows users to create multiple notes and delete notes whenever they are no longer needed.

## 🚀 Features

- ➕ Create new notes
- 📝 Add text to each note
- 🗑️ Delete notes
- 📄 Create multiple notes
- 📱 Responsive design
- 🎨 Clean and simple user interface
- ⚡ Built with vanilla JavaScript
